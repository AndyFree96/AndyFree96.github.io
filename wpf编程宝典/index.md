# WPF编程宝典 第4版 (Matthew MacDonald)


Windows桌面应用开发经历了从 Win32 API、MFC，到 Windows Forms，再到 WPF(Windows Presentation Foundation)的演进。相比传统桌面开发技术，WPF 不仅仅是一个新的 UI 框架，更是一套重新定义桌面应用开发方式的技术体系。它将界面描述、数据绑定、图形渲染、动画效果、样式模板以及应用逻辑进行了更清晰的分离，使开发者能够构建更加现代化、可维护、可扩展的桌面应用程序。

作为一名从事 C#/.NET 开发的工程师，WPF 一直是 .NET 桌面开发体系中不可绕过的重要技术。虽然近年来 Web、移动端以及跨平台技术快速发展，但在工业软件、自动化设备上位机、生产管理系统、视觉检测软件等领域，基于 WPF 的桌面应用仍然具有非常广泛的应用场景。尤其是在工业自动化领域，设备控制软件通常需要复杂的交互界面、实时数据展示、丰富的图形化配置以及良好的工程扩展能力，而 WPF 凭借其强大的 UI 描述能力和 MVVM 架构模式，依然是构建此类应用的重要选择。

[《WPF编程宝典：使用C# 2012和.NET 4.5（第4版）》](https://book.douban.com/subject/25785318/)是 WPF 领域非常经典的学习资料之一。本书由浅入深地介绍了 WPF 的核心概念，包括 XAML、布局系统、控件体系、依赖属性、路由事件、数据绑定、资源、样式、模板、动画、图形绘制发等内容。相比简单介绍 API 的书籍，本书更注重帮助开发者理解 WPF 背后的设计思想，以及如何利用 WPF 构建真正工程化的软件系统。
