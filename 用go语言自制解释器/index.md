# 用Go语言自制解释器 (Thorsten Ball)


在过去的学习过程中，我接触过C#、C++、Python、JavaScript等多种编程语言，也阅读和分析过一些优秀开源项目的源码。但对于Go语言，只停留在“接触过”的阶段，并没有进行过系统学习。相比于从语法、标准库、工程实践开始学习一门新语言，我更希望通过一个完整、有意思的项目进入Go的世界。因此，我选择了[《用Go语言自制解释器》](https://book.douban.com/subject/35909085/)这本书作为Go语言学习的切入点。该书并不是一本单纯介绍Go语法的教程，而是通过实现一个完整的解释器。对于我来说，这样的学习方式非常适合。一方面，通过实现解释器，可以深入理解编程语言背后的工作机制。另一方面，在这个过程中，也可以接触Go语言的核心特性。相比单独学习Go语言，通过一个真实项目驱动学习，可以更加深刻地理解“为什么Go会这样设计”，以及这些语言特性在实际工程中的价值。因此，本文并不是[《用Go语言自制解释器》](https://book.douban.com/subject/35909085/)的简单读书笔记，而是一次通过实现解释器深入学习Go的过程。
